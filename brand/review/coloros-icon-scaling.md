# 桌面图标缩放验证

## 通用问题与修复

基线 `62580247ed78724a29ceccc7643b2620e1279807` 的普通、夜间和单色前景均使用 24dp 固定边距。自适应图标的前景边界变化时，固定像素边距所占比例也会变化。保留背景、原始图案和文字，将三个资源的边距均改为 `22.222222%`，在 108 坐标下对应前景画布宽 60；百分比随 Drawable 的边界变化，而不改变原图。

多尺寸回归先运行在基线上：Robolectric Android 34 的资源加载与渲染中，160dpi 下 64px 和 256px 边界的可见字标宽分别约为边界宽的 43.75% 和 78.125%，触发比例断言。相同回归改为相对边距后通过。覆盖常规/圆形图标、白天/夜间、彩色/单色、160/320dpi 和 64/128/256px；检查前景非空、尺寸比例及位置。它是框架模拟，不代表 ColorOS 桌面实测。

`LauncherIconRenderingTest` 在仪器化测试中通过 PackageManager 加载应用图标，并在真实 Android 框架中验证多尺寸、多密度、日夜及单色前景；记录实际 drawable 的 intrinsic size 和 optical insets，输出白天/夜间 64、128、256px 图像。CI 附加采集系统应用详情、桌面和应用列表的截图及 UI 层级（可用时）。框架生成的图片是不同尺寸渲染样本，不是文件夹或系统设置页面截图；具体是否捕获到目标图标须目视检查对应 artifact。

原始图 `brand/launcher-original.png` SHA-256 `8a505bee118bcf7bf984b594e8e01bcacd4b963cd7f5859f936caf3e34527bdc`，透明前景 `app/src/main/res/drawable-nodpi/launcher_mark.png` SHA-256 `474283125aeb1736517c19ec44f5c2e22eacee534e2ebd7fe27919a7656ad4ad`；本次两者均未改动。开屏图案及其 328dp 加载页校准未改动。

## ColorOS 17 真机结果

用户声明使用 ColorOS 17，但设备型号、完整系统构建号、桌面版本与主题设置、此前截图对应 APK 的 SHA 尚未确认。没有 ColorOS 桌面设备，不能推断其遮罩或归一化算法；本次候选待同一推荐 APK 在用户设备上复测，不能称为已兼容 ColorOS 17。桌面应用名称及完整“结形＋织问”均需确认。不要通过清空桌面数据刷新缓存。

开屏真实逐笔动画和系统到加载页的动画接力仍未完成，是 PR #6 的独立阻断项；本次图标修复不关闭该事项。
